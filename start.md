### **Запуск**

Для запуска всех сервисов выполнить команду:

```bash
docker-compose up --build
```

Эта команда соберет Docker-образы для каждого сервиса и запустит их.


RabbitMQ Management Console доступна по адресу: 
```
http://localhost:15672
```
